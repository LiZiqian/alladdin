## 本轮主要修复

| 范围 | 触发问题与修复后行为 |
| --- | --- |
| 增量写入 | 批量任务也校验 revision；拒绝被隐式转成整数的布尔/小数版本。创建/删除开关必须为 JSON 布尔值，字符串 `"false"` 不会执行删除。跨池样机写入、非法 sampleIds、销毁事件越界均在写入前拒绝，并验证拒绝前后数据库不变。 |
| 归档与占用 | 旧归档任务的非终态状态不再误占用、阻止删除或绕过结束任务的样机释放要求；删除父阶段后仍保留归档履历及其关键词搜索。 |
| 完整统计与筛选 | 新增任务的“已有任务”和样机的“已测”使用服务端完整聚合，不随已浏览页数变化；空集合也有明确语义。人员完整姓名/工号、深层关键词回退和 `%`/`_` 字面搜索保持一致。 |
| 异步表单 | 迟到读取不会在离开页面后弹出旧详情、配置或销毁确认；选择器不覆盖已保存状态或未保存备注。缺失样机缓存、异步查重后的对象替换、任务已结束、旧弹窗延迟回调都有对应保护。 |
| 三方合并 | 区分字段缺失与 null，真正移除已删除字段，同时保留其他客户端的后续编辑。客户端只插入/删除时保留服务器排序；显式重排仍生效。消除大列表重复线性查找。 |
| JSON 与 HTTP | HTTP 和外部包入口统一拒绝 NaN、Infinity、超出有限数值范围的整数、重复字段、孤立 Unicode surrogate 和过深嵌套。浏览器异源写入被拒绝；正常同源和无 Origin 的 API 客户端保持兼容。小体积拒绝请求有界清理，避免 Windows 关闭连接时丢失错误响应。图片 MIME 脏值不再注入响应头或触发编码异常。 |
| 导入决策 | 同 ID 任务的草稿、结果、日志和样机关联进入既有字段冲突界面，不再静默忽略；选择导入侧缺失字段会移除旧值。V2 新项目导入不再套用旧格式默认值、凭空增加可选字段。SN 身份合并导致的条件占用提前呈现，明确目标池失效时拒绝，重复 CSV/XLSX 业务列给出错误。 |
| 迁移与照片 | 预览提交拥有独立租约，过期/容量清理和重复提交不会删掉正在使用的数据；缓存计入解压后大小。提交后异常清理先核对数据库引用，保留已提交原图及缩略图。ID 合并后重写实际照片 URL，选择性导出补齐草稿、快照和日志依赖。 |
| 单机档案 | 多次迁移不再不断生成重复履历。按来源部署/任务归并，使用权威摘要及来源版本，保留日期精度、明确空结果和后续结果更新；旧包晚到不会覆盖新摘要。分页使用一致读快照，跨 state/history 读取发生更新时明确要求重试。 |
| 历史规范化 | 普通文本和资源路径不因状态兼容替换而改字；保留缺旧 schema 标记的真实事件，以及问题记录 ID、任务来源和记录日期。前后端同族路径均补回归。 |
| UI 可达性 | 390–1036px 宽度下，阶段策略/BOM 左右区域可以整体横向滚动，SKU 和删除控件可到达；桌面保留既有冻结列。新增任务表保留可读列宽和横向滚动，测试项名称、数量输入不再被挤没。 |

完整反例、文件归属和覆盖范围见：[后端复核](../output/system-audit-20260921/backend-followup.md)、[前端复核](../output/system-audit-20260921/frontend-followup.md)、[数据迁移复核](../output/system-audit-20260921/transfer-followup.md)。三条路线分别交叉审查其他路线的改动，没有只依赖作者自己的回归结果。

## 已知边界

- 当前分支仍没有历史固定 IPv4 ACL 实现；四套相关独立测试引用缺失模块。Origin 检查只约束浏览器异源写入，不代表身份认证或 ACL。
- `.github/workflows/sync-shared-release.yml` 仍读取不存在的 `VERSION`，且限定 7.2 版本线；当前为 7.3.0。正式发布前需要确定 7.3 的标签/Release 策略。本轮未运行发布流程或移动远程标签。
- 本机忽略 `dev/` 与 `AGENTS.md`；定位图和旧测试适配属于本地验证资料。新增 `tests/`、源码与本报告可随后续审阅提交，需与开始前既有改动一起明确区分。
- 覆盖证据只支持已列出的路径、数据和并发窗口；不能据此保证任意历史坏数据、无限大单实体或全部浏览器组合都不存在缺陷。
